# إبداع | IBDAA Launcher 1.5

مشغّل سطح مكتب بهوية بصرية عربية مخصصة، يدير البرامج من خلال روابط GitHub Releases.

## المتطلبات
- Windows 10/11 x64
- Node.js LTS وnpm
- اتصال بالإنترنت لجلب إصدارات GitHub وتنزيل الملفات

## تشغيل المشروع
```powershell
npm install
npm start
```

## بناء نسخة Windows
```powershell
npm run dist
```
ستجد المثبّت والنسخة المحمولة داخل `release/`.

## إضافة روابط GitHub داخل الكود
افتح الملف `src/catalog.js`. لكل برنامج عدّل الخاصية `repo`:
```js
{ id: "musammim", name: "مصمم", english: "Musammim",
  category: "الصور", description: "محرر الصور والتصميم الرقمي",
  repo: "YOUR_GITHUB_USERNAME/YOUR_REPOSITORY", color: "#3678E8" }
```
يمكنك استخدام `owner/repo` أو `https://github.com/owner/repo`.
احفظ الملف ثم أعد تشغيل المشغّل. لا يلزم وجود ملف إعدادات خارجي.

## آلية التنزيل
- يتصل المشغّل بواجهة GitHub العامة ويقرأ أحدث Release مستقر.
- يعرض ملفات Release Assets وأحجامها وملاحظات الإصدار.
- ينزّل الملف الذي تختاره داخل مجلد بيانات التطبيق، بمجلد مستقل لكل برنامج.
- يدعم متابعة تقدم التنزيل وفتح مجلد الملفات من النظام.

## حدود مقصودة في الإصدار الحالي
- لا يقوم ببناء المستودع المصدري أو استخراج الأرشيفات تلقائيًا.
- لا يشغّل ملفات EXE/MSI تلقائيًا؛ راجع الملف وافحصه ثم افتحه بنفسك.
- يجب أن يحتوي المستودع على GitHub Release منشور وملفات مرفقة حتى يظهر تنزيل.
- لم تتم إضافة التحديث الصامت أو التوقيع الرقمي بعد.
- واجهة النافذة مخصصة وبدون إطار Electron الافتراضي، لكن التطبيق ما زال يستخدم Electron كمحرك تشغيل.

## الأمن
- التنزيل محصور في HTTPS وروابط أصول GitHub المعروفة مع التحقق من التحويلات.
- `contextIsolation: true` و`nodeIntegration: false` و`sandbox: true`.
- لا يحتاج المشغّل إلى GitHub token للمستودعات العامة. لا تضف أسرارًا أو رموز وصول إلى `catalog.js`.
